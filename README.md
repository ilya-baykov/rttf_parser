ч# RTTF parser

Асинхронный парсер профилей игроков RTTF.

## Что вытаскивает

- базовый профиль игрока: имя, ник, текущий RTTF, город, год рождения, рука;
- даты регистрации/последнего визита, если они есть на странице;
- ссылки из профиля: комментарии, прогнозы, результаты, соперники, статистика;
- общую статистику: место в рейтинге, турниры, игры, победы/поражения, первый турнир, любимый зал;
- RTTF Cup допуск;
- максимальный рейтинг и дату максимума;
- историю рейтинга из JS-графика;
- лучшие победы;
- награды по залам;
- последние результаты турниров и матчи внутри турниров.

## Установка

```bash
pip install -e .
```

## Запуск

```bash
rttf-parser \
  https://rttf.ru/players/193138 \
  https://rttf.ru/players/242733 \
  --output-dir parsed_rttf_players \
  --concurrency 5
```

Или через файл:

```bash
rttf-parser --urls-file urls.txt
```

## Формат `urls.txt`

```txt
https://rttf.ru/players/193138
https://rttf.ru/players/242733
```

## Поведение при ошибках

Парсер не падает всем батчем из-за одной плохой ссылки. В итоговом JSON есть две секции:

- `ok` — успешно распарсенные игроки;
- `failed` — URL, тип ошибки и сообщение.

## Почему `httpx`

`httpx.AsyncClient` позволяет загружать несколько страниц параллельно, но `concurrency` ограничивает нагрузку на сайт.
